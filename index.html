Sobre mí

Infraestructura, seguridad electrónica y software

Soy Analista de TI con 3 años de experiencia en Spectra Ingeniería (Cali). Administro el entorno Microsoft 365 / Entra ID de la empresa y su red (firewall Sophos, switches Allied Telesis, Windows Server y Ubuntu). También configuro sistemas de videovigilancia y control de acceso en proyectos de clientes.

Además desarrollo software para necesidades reales: una plataforma interna de TI y el sistema del Centro de Servicios que reemplazó un Excel. Estudio Tecnología en Sistemas en la UNIAJC.

  • Administro Microsoft 365 / Entra ID y apoyo la red de la empresa
  • Configuro CCTV y control de acceso: Hikvision, Milestone, Pelco, BioStar 2
  • Desarrollo con Next.js, TypeScript, Laravel, PHP y Google Apps Script
