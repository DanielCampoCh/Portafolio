01 / PROYECTO ACADÉMICO
SISC — Sistema de Información de Seguridad Ciudadana
Cali · Colombia · Proyecto Integrador 5° Semestre

Plataforma web para la gestión y visualización de datos de seguridad ciudadana en Cali. Incluye mapa interactivo con geolocalización de incidentes, sistema de comentarios, registro y consulta de eventos por zona. Desarrollado con Laravel en el backend, PHP, y base de datos MySQL administrada con XAMPP.

Cali · Colombia · Proyecto Integrador 4° Semestre

03 / PROYECTO PROFESIONAL
GLPI — Sistema de Gestión IT · Spectra Ingeniería
Cali · Colombia · Entorno Empresarial Real

Configuración e implementación completa de GLPI (sistema ITSM open-source) en entorno empresarial para Spectra Ingeniería. Desplegado en máquina virtual Ubuntu Server, integrado con Active Directory para autenticación de usuarios. Gestiona inventario de más de 59 computadores, 3.300+ programas, 42 monitores, 38 teléfonos y 16 impresoras. Incluye mesa de ayuda con más de 25 categorías de tickets (VPN, soporte Microsoft 365, control de acceso biométrico, gestión de periféricos y más).
